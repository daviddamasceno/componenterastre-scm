# ComponenteRastre

Repositório único de itens de configuração de software (SCIs) do projeto **ComponenteRastre**.

O time de desenvolvimento e o time de operações compartilham neste remoto a última versão dos artefatos. Mudanças solicitadas por operações são registradas e devolvidas aqui após trabalho na cópia local.

## Pedido do time de operações

Operações solicitou o registro de um rastreador mínimo de SCI para tornar visível a inclusão de novos itens de configuração neste repositório. A alteração foi aplicada na cópia local e será publicada no remoto após `commit` e `push`.
